# Projeto: Vogais

Este projeto foi desenvolvido no **Visual Studio Code (VS Code)** com o objetivo de praticar conceitos básicos de programação, como manipulação de strings, estruturas de repetição e condicionais.

A aplicação identifica e exibe as vogais presentes em uma palavra ou frase informada pelo usuário. Durante o desenvolvimento, foram utilizados conceitos fundamentais da linguagem, como variáveis, laços de repetição (`for`) e verificações condicionais (`if`), proporcionando uma melhor compreensão da lógica de programação.

## Objetivo

* Identificar as vogais de uma palavra ou frase.
* Praticar lógica de programação.
* Aprender a manipular textos utilizando uma linguagem de programação.

## Tecnologias Utilizadas

* Visual Studio Code (VS Code)
* Linguagem de programação utilizada no projeto (substitua pelo nome da linguagem, por exemplo: JavaScript, Python ou Java).

Este projeto faz parte dos meus estudos e foi criado para reforçar conhecimentos básicos de programação e desenvolvimento de software.
